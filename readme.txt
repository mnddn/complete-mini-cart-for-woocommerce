== Description ==
Enhance your WooCommerce store with **Complete Mini Cart for WooCommerce** – a powerful, lightweight, and fully customizable mini cart plugin. Improve user experience with an AJAX-powered cart and real-time updates.

✨ **Key Features:**
- 🚀 **AJAX-Powered Mini Cart** – Update cart items instantly without page reloads.
- 🛒 **Mini Cart as Menu Item** – Improve accessibility and boost conversions.
- 📑 **Elementor Widget** – Get a fully  customizable Elementor Widget.
- 🎨 **Fully Customizable Mini Cart** – Modify colors, typography, and layout to match your theme.
- 🔄 **Live Quantity** – Display real-time cart changes.
- 📱 **Mobile-Friendly & Responsive** – Works perfectly on all devices.
- ⚡ **Lightweight & Fast** – Optimized for performance and speed.
  
💡 **Boost your WooCommerce store’s conversion rate with a user-friendly and a complete mini cart experience!**

== Installation ==
1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the ‘Plugins’ menu in WordPress.
3. Navigate to **WooCommerce → Mini Cart Settings** to configure Shortcode options.
4. Search for **Mini Cart** in the Elementor Page Builder
4. Enjoy an optimized cart experience on your store! 🚀


== Frequently Asked Questions ==
= Does this plugin work with all themes? =
Yes! **Complete Mini Cart for WooCommerce** is designed to work with any WooCommerce-compatible theme.

= Is this plugin compatible with AJAX-based checkout? =
Absolutely! The mini cart updates dynamically without interfering with the checkout process.

= Can I customize the appearance of the mini cart shortcode? =
Yes! The plugin provides built-in customization options for styling and positioning the cart.

= Does it provide an actual Elementor Widget
Yes! The plugin provides built-in support for one Elementor Widget for styling and positioning the cart. You can find it in Elementor Page Builder by seraching for 'Mini Cart'.

= Can we make the icon and cart count box floating?
Yes, you can. You can do it with the Elementor Editor easily. For the Shortcode you need to add some custom CSS.
